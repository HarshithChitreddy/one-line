# One Line

I really enjoy playing Zip on [LinkedIn Games](https://www.linkedin.com/games), so I built One Line as my own take on a daily path puzzle. I wanted to make something quick to play, satisfying to solve, and easy for anyone to try.

## How to play

Start at **1** and draw one continuous path through neighboring squares. Visit the numbered squares in order, cover every square, and finish on the last number. Thick borders are walls you cannot cross.

You can drag, tap squares, or use the arrow keys. There is a new daily puzzle at midnight Pacific, and practice mode is there whenever you want another one. Your progress saves in your browser, so you do not need an account.

## Run it locally

Run `npm run dev`, then open <http://localhost:4173>. Run `npm test` to check the puzzle rules.

I’ll keep improving One Line with more puzzles and small touches that make it nicer to play.
